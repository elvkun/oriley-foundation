Platform status

Current implementation

Flow is O’Riley Foundation’s cross-platform product: native Android, iPhone and iPad apps, plus a browser app, designed to connect through shared backend services.

The Flow repository is building toward this architecture. The Android app is retained, while iOS and web currently have starter screens. Shared authentication, messaging, data, payments, and production APIs remain backend work and should be described as available only when implemented.
