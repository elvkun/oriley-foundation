# O’Riley Foundation

The O’Riley Foundation website describes the parent company and its digital platform portfolio, including Ryvo and ZimLive.

## Portfolio relationship

- **O’Riley Foundation** is the parent company.
- **Ryvo** is a cross-platform product targeting native Android, native iPhone and iPad, and web clients backed by shared services. Its repository is [`ryvo-hardened`](https://github.com/elvkun/ryvo-hardened).
- **ZimLive** is also presented as a platform in the portfolio. Its application scope and relationship to Ryvo should remain distinct unless product decisions explicitly unify them.

The Ryvo repository currently retains its Android application and includes starter iOS and web screens. The backend, production authentication, messaging, payment integrations, and shared production APIs are not represented as complete in this website.

## Website

This is a static HTML page. Open `index.html` in a browser or deploy the repository with a static hosting provider. Tailwind CSS and fonts are loaded from external CDNs.
