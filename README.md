# O’Riley Foundation

The O’Riley Foundation website describes the parent company behind Flow.

## Portfolio relationship

- **O’Riley Foundation** is the parent company.
- **Flow** is a cross-platform product targeting native Android, native iPhone and iPad, and web clients backed by shared services. Its repository is [`ryvo-hardened`](https://github.com/elvkun/ryvo-hardened). The marketing site in the legacy-named ZimLive repository now uses the Flow product name.

The Flow repository currently retains its Android application and includes starter iOS and web screens. The backend, production authentication, messaging, payment integrations, and shared production APIs are not represented as complete in this website.

## Website

This is a static HTML page. Open `index.html` in a browser or deploy the repository with a static hosting provider. Tailwind CSS and fonts are loaded from external CDNs.

The page links to `sitemap.xml` and `robots.txt` for `www.orileyplatforms.com`. The sitemap lists the home page only; section fragments are in-page navigation, not separate sitemap pages. Contact channels and legal policy links are intentionally shown as unavailable until verified details are supplied.
